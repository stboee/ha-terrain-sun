## Lokal horisont

- Velg mellom **Utsnitt**, **360°**, **Solbane** og **Månebane**. **Solbane** erstatter **Vis hele solbanen**. De tidligere innstillingene for solbane virker fortsatt som startvalg.
- **Månebane** viser hele solbanen og månebanen gjennom valgt lokalt døgn, også under terrenglinjen. Aksene gir plass til begge banene.
- **Vis skumring** slår fargebånd og tegnforklaring av og på i alle visninger. Aksene, terrenget, solbanen og månebanen beholder posisjonen.
- Oppdatert skjermbilde i README viser **Månebane** med terrengprofilen fra Øyer.
